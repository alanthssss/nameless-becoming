庭院出发 → 沿花路采蜜和取材 → 回庭院交付 → 买成长 → 开放紫花地 → 备好蜂巢花蜜。
每区一条深入花路、一条短材料分岔和一个远端。花与材料会生长、成熟、衰败并补充；小芽暂不可采，盛开和将谢阶段可采。材料震落后靠近拾取，久留会消散。

标题或暂停 → 设置 → 查看或改键。飞行页列出当前绑定，菜单、成长树和花湾可按需切换。选择键盘和鼠标或游戏手柄，点选一个动作的按键即可更换。Esc 或手柄 B 取消。改键自动保存，可恢复全部默认按键。
默认键鼠：WASD / 方向键飞行。E 或鼠标左键在花旁按住采蜜，在设施或返程木牌附近点按交互。Q 朝蜜蜂面向振翅，右键朝鼠标指针振翅，可按住连发。按住空格蓄力，松开冲刺。Esc 暂停，M 静音。
默认手柄：左摇杆或十字键飞行。A（下）交互或按住采集，X（左）朝蜜蜂面向振翅，RB 按住蓄力、松开冲刺。Start 暂停。蜂舞中按冲刺键跳过。
菜单用方向键或十字键选择，Enter / A 确认，Esc / B 返回。成长树可用方向键、左摇杆或十字键选格，Enter / A 购买。右摇杆移图、LT / RT 缩放，鼠标可拖空白和滚轮缩放。
开局每区16处花源、3处材料，花位疏散。花地繁盛两级成长依次开放24/4、36/6处资源；花再生由20秒缩短到14秒、10秒，材料由44秒缩短到30.8秒、22秒，下趟出发生效。
初始续航36、容量6；成长可达70续航、16容量及双花采集。材料用于成长，空挥不扣动作体力。体力耗尽由同伴送回，损失一半花蜜，材料保留。完成储粮后仍能自由探索。
