# 雨来之前 · 四季旅程 Alpha 0.6.0

四区16关现已连接为从标题到结尾的完整开发版。保留春天四关的飞行、救援、蓄力冲刺、连续借风、追雨与三首音乐；新增夏、秋、冬十二关，共60个手工遭遇。它是全篇Alpha，商业美术、真人首通时长和发行验收尚未完成。

## 打开这一版

macOS 包：`outputs/swarm-flight/2026-10-22-full-alpha/雨来之前·四季旅程.app`。双击同目录「开始试玩.command」，标题应为「雨来之前 · 四季旅程 Alpha 0.6.0」。Enter从春天开始；标题页Tab循环选择春／夏／秋／冬，随后Enter出发。选择后续章节会开始一趟新旅程；要保留当前旅程，选择继续存档。

Godot 4.6.2可直接打开本目录`project.godot`，或运行`play.command`。这是独立飞行工程，不启动旧年度工程。旧0.5.2及更早包保留。

## 四季的安排

| 区域 | 关卡 | 主要判断 |
|---|---|---|
| 春 · 归家 | 01–04 | 学会飞行、解救伙伴、连续借风、甩开追雨，回到老树 |
| 夏 · 花篱外 | 05–08 | 先看落点再选高低风路；判断喷嚏花空档；借风或普通飞行 |
| 秋 · 旧果园 | 09–12 | 接力中断后重新选路；斜向穿缝；冲帘省路或绕行留力 |
| 冬 · 暖廊与老树 | 13–16 | 综合选路、雨带和体力；第15关高潮，第16关短尾声 |

章节边界有4.5秒季节衔接，普通终点2.4秒。穿过花铃叶拱／树洞就立即完成并保存；落脚演出不再耗体力或计时。Enter可提前继续，Esc或失焦暂停。04是春天归家，16才是整作结尾。

小满和画眉在安全落脚点作简短回应；同伴不跟飞、不新增碰撞或雨滴损耗。枯花、果园牌和灯仅作场景标识；有箭头的风花才会借力。

## 操作与规则

- 方向键／WASD飞行；空格按住约0.4秒，光环亮起后松开冲刺。长按不会额外增加距离。
- 冲刺可救伙伴、借风、冲开干叶帘、击散雨滴和安抚喷嚏花；实心茎干需要绕行。
- 宽叶亭依次保存并以每秒24体力恢复；可以直接继续，不强制等满。两条分路共用落脚点。
- 飞行每秒耗2体力，冲刺耗20；晨露最多恢复12，救援最多恢复40，风花最多恢复8。界面报告实际恢复值。
- 灰雨滴、喷嚏水珠伤体力，棱面晨露是补给。雨关有后方雨幕与独立露天预算，叶下暂停；普通关显示旅程计时。
- 护雨叶保护5秒，可挡雨与喷嚏，仍耗飞行／冲刺体力和露天时间；不能穿实心墙。
- R回到最近落脚点；Esc暂停；M开关声音。暂停会冻结游戏与演出。

## 进度

全篇使用独立文件`before_the_rain_journey_v1.json`（version 5 / content_revision 7）。不读取、迁移或覆盖旧四关`before_the_rain_chapter_v4.json`。春天救援仍为4／2／1／1，后续角色只是邻居，伙伴总数仍8只。

关中继续回到已存宽叶亭；已穿过终点则进入下一关；16关完成后可重看结尾。收集不锁出口。标题选章会重开当前Alpha旅程，不改旧四关档；结束页统计只反映这趟旅程。

## 开发验证

```sh
godot --headless --path prototypes/swarm-flight --editor --import --quit
godot --headless --path prototypes/swarm-flight --script res://verify.gd
godot --headless --path prototypes/swarm-flight --script res://ui_verify.gd -- --swarm-qa
godot --headless --path prototypes/swarm-flight --script res://audio_verify.gd
```

模型检查覆盖全16关直达／全露路线、所有安全存档点、分路互斥、资源守恒、终点和存档边界；首章另跑无护雨、穿亭不停满、救援后回退三条回归路线。`--new-levels`可单独验证新增12关的24条路线。UI检查用Viewport分发真实方向键和空格，连续完成16关，检查15次衔接、完整结尾、暂停、选章、跨季保存继续和写盘失败提示。

`route_driver.gd`知道所有答案，仅提供普通按键，不修改模型、地图、资源或位置；它不代表玩家乐趣或真人首通时长。原生截图用`SWARM_FLOW_CAPTURE_DIR`；`--swarm-qa`隔离真实进度，存档验证只写独立临时路径。每次交付事实见主设计文档SF-R20和输出目录`build-receipt.json`。

美术由`world_view.gd`程序绘制，音乐由`sound.gd`原创合成，来源与哈希见`asset-manifest.json`。1280×800逻辑画面保比例缩放；macOS universal包排除测试脚本。四季背景与角色仍是Alpha美术，未通过商业成品审美验收。Windows／手柄／Steam／独立玩家验证待后续完成；首通2～3小时仍是未验证的商业制作目标。
