# 雨来之前 · 第一章「归家」

0.4.3 是四关相连的完整飞行章节：晨光菜圃 → 喷泉花桥 → 雨中停走 → 归巢之路。救出八只伙伴，让它们先回家，再独自飞回老树；每关七处命名路段与叶下落脚点，包含开场、关内恢复、关间衔接、结尾和重玩。保留 0.3.1 的飞行与蓄力操作、庭院卡通和三首原创音乐。

伙伴获救后短暂回应并沿弧线飞出画面，不再跟随玩家。HUD「已救」只统计获救伙伴，不含自己；救援立即保存，伙伴不参与碰撞、雨滴或体力损耗，结尾已在树巢等你。

## 打开与操作

本轮 macOS 包位于 `outputs/swarm-flight/2026-10-21-rescue-departure/雨来之前·第一章.app`，窗口标题应为「雨来之前 · 第一章 · 归家 0.4.3」。退出旧版窗口，再用同目录「开始试玩.command」打开；选「从头开始这一章」连续体验四关。源码使用 Godot 4.6.2 打开本目录的 `project.godot`，或运行 `play.command`。

- 方向键 / WASD：八方向飞行，松开迅速停稳。
- 空格按住约 0.4 秒，光环亮起后松开冲刺；蓄力时能改方向，就绪后继续按住不会增加射程。
- 冲刺可救卷叶里的伙伴、打开干叶帘、借风花接力、击散雨滴、安抚喷嚏花。厚茎必须从空隙绕行。
- 方向标指向本段伙伴或下一处叶下；HUD 显示关卡、当前小段、目标与完成进度。按顺序到达叶下，完成本关后飞向出口。
- 大叶下安全、恢复体力并保存进度；晨露是可选绕路，收集不影响通关。
- Esc 暂停，R 回到最近落脚点，M 声音开关。菜单用上下键 / Tab 选择，Enter 确认，也可点击。
- 关间衔接停留 1.6 秒，Enter 可提前；新关和存档继续都等待重新操作后出发。

体力 100，露天每秒消耗 2，冲刺花费 20；雨击消耗 30、喷嚏水珠消耗 12。救援补充最多 40，首次借风最多 8，晨露最多 12，首次安抚喷嚏花最多 10；叶下每秒恢复 24。体力条每格 20，蓄力显示冲刺成本。第三、四关显示当前路段的“露天”倒计时，与身后追来的雨幕分别反馈；新叶亭重置下一段时间，叶下和暂停时停表。体力耗尽或时间归零会回到最近安全落脚点并补满体力，不丢失已保存的伙伴。

连续风花之间有风路指引，一次冲刺接上多朵会显示“连续借风 ×2／×3”，不需要在花间重新蓄力。第三、四关的雨幕按路段交替推进快慢：普通巡航仍快于最快雨幕，绕路／瞄准会消耗距离优势。天气提示区分逼近、甩开和叶下安全；雨幕追上消耗30体力，叶下停住，下一处新叶亭恢复距离。结尾雨幕退场。

每关七颗晨露，全章 28 颗。未到落脚点的收集会随失误回滚；已保存的收集及跨关统计保留。救援立即记住新伙伴，但恢复位置仍为最近叶下。独立 `before_the_rain_chapter_v2.json` 保存关内进度；关闭后通过标题「继续」恢复。通关存档可查看结尾。旧短篇 v1 和旧年度工程存档不会被读取或改写。

## 验证与边界

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://verify.gd
godot --headless --path . --script res://ui_verify.gd -- --swarm-qa
godot --headless --path . --script res://audio_verify.gd
godot --headless --path . --quit-after 3 -- --swarm-qa
```

检查退出码、成功标记，且日志没有 `SCRIPT ERROR` / `ERROR:`。规则检查覆盖原有控制响应、四关完整路线、体力守恒、28 露绕路、检查点前进与救援保留、合法 / 畸形存档。场景检查通过 Viewport 分发方向键和空格，完成四关与结尾，验证自动 / Enter 衔接、暂停 / 失焦、提示优先级、重玩与标题继续。`route_driver.gd` 只发送普通输入，不移动角色或改写地图，是开发者已知答案路线，不代表陌生玩家。原生截图可通过 `SWARM_FLOW_CAPTURE_DIR` 指定目录；`--swarm-qa` 不触碰真实存档，独立原生保存测试可使用 `--progress-file=/absolute/test.json`。

美术由 `world_view.gd` 绘制，音乐由 `sound.gd` 原创合成，无运行时网络下载。四种庭院配色、叶亭标识和地标服务方向识别；末关晚霞收束归程。来源与验证见 `asset-manifest.json`。画面按 1280×800 保比例缩放。macOS universal 包包含全部运行资源，并排除开发测试脚本；Windows / Linux 安装包尚未验收。

完整第一章是体验验证产物。Alan在0.4.0整章结尾给出连续冲刺、追赶有趣的正反馈，截图游戏计时12:08、同行9只、晨露26颗。这是一位创作者玩家的实玩证据，不代表独立玩家分布或商业质量；原20～30分钟目标没有据此成立，不以延长路程凑时长。Alan复玩0.4.1后认为核心和基本节奏成立，主要指出造型生硬、角色动作缺少生气。0.4.2完成造型／动作实验后，Alan明确要求取消伙伴跟飞。0.4.3按该决定改为救援离场，玩家独自继续，音乐和路线保留；0.4.2包保留对照，v2进度兼容。完整制作证据、已知限制与下一检查点见[制作说明](../../docs/design/swarm-flight-game-20261020.md#2026-10-21-第一章归家制作-sf-r06)。
