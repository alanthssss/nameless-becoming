# 雨来之前 · 第一章「归家」

0.5.1 是四关连贯的一章：晨光菜圃 → 喷泉花桥 → 雨中停走 → 归巢之路。20 个手工遭遇共用 9 个宽叶亭；救出八只伙伴，让它们先回家，最后独自飞回老树。保留已有飞行、蓄力冲刺、连续借风、追雨、伙伴离场和三首音乐。

本轮根据 Alan 完整试玩后的“露珠与叶亭重复”反馈，调整整章事件衔接：救援补给接续飞行／借风，花桥稳路有中途补给，雨庭在借风及救援冲刺前补给，末关合并高潮前休息并缩短回家路。晨露不再按每段一颗生成。01、02无随机落雨；04救援、暖窗和抵达段停止新增随机雨滴，远方云带仍预示下一片雨。已有雨滴继续运动，不在切段时凭空消失。

沿用已有飞行、体力参数、救援4／2／1／1、两次五秒护雨、伙伴离场、程序绘制美术和三首音乐。

## 打开这一版

macOS 包：`outputs/swarm-flight/2026-10-21-event-pacing/雨来之前·第一章.app`。运行同目录「开始试玩.command」，窗口标题应为「雨来之前 · 第一章 · 归家 0.5.1」。选择「从头开始这一章」完整体验四关。旧 0.5.0 包留在 `2026-10-21-chapter05/`，旧 0.4.4 也保留。

源码使用 Godot 4.6.2 打开本目录 `project.godot`，或运行 `play.command`。这里是独立原型，不启动旧年度工程。

## 操作与规则

- 方向键／WASD 飞行；按住空格约 0.4 秒，光环亮起后松开冲刺。长按不会额外增加距离。
- 冲刺救出卷叶里的伙伴、借风接力、冲开干叶帘、击散雨滴、安抚喷嚏花；实心茎干需要绕行。
- 每关五段经历，存档区间按关卡为 2／2／3／2。经过宽叶亭自动保存，24 体力／秒恢复；可以继续向前，不要求等满。
- 飞行每秒消耗 2 体力，冲刺消耗 20。晨露最多恢复 12，救援最多恢复 40，风花最多恢复 8；界面报告实际恢复值。
- 灰雨滴和喷嚏水珠会伤体力；棱面晨露是沿途补给，也记录收集数。雨庭与归巢有身后追来的雨幕和独立的露天时间预算，叶下均暂停。
- 轻触护雨叶获得五秒保护，挡落雨、喷嚏水和雨幕接触伤害。保护期间仍耗飞行／冲刺体力、露天时间，墙仍会挡路。最后一秒轮廓提醒；漏拿也可通关。
- R 返回最近恢复点；Esc 暂停，M 开关声音。暂停冻结护雨和雨幕。

## 进度

四关晨露为 2／1／3／0，共 6 颗，可选收集不锁出口。主线需要救齐该关伙伴、依次经过宽叶亭；伙伴即时记住，恢复位置仍在安全处。同伴离场动画没有碰撞或生命值，结尾有八只伙伴等候。

重排地图使用独立 `before_the_rain_chapter_v4.json`（version 4 / content_revision 6）。不读取、覆盖或迁移旧 v2／v3。退出后通过标题「继续」回到已存叶亭，已通关可查看结尾；护雨消耗随安全快照保存，剩余秒数不保存。第一次 0.5.1 试玩从头开始。

原生截图使用 `SWARM_FLOW_CAPTURE_DIR`。`--swarm-qa` 不读写真实进度；存档流程测试只写独立临时路径。制作与验收事实记在主设计文档 SF-R13 的实施回执及本地 `build-receipt.json`。

美术由 `world_view.gd` 绘制，音乐由 `sound.gd` 原创合成，来源和校验在 `asset-manifest.json`。1280×800 逻辑画面保比例缩放；macOS universal 包排除测试脚本。Windows／Linux 安装、Steam 和陌生玩家验收尚未完成。
