# 雨来之前

现有三段整体打磨的 Godot 实时飞行样板章。风把伙伴吹进了卷叶；你带蜂群穿过花桥，在暴雨到来前进入老树的树洞。包含开场、三个连续段落、失误恢复、结尾与重玩。

## 打开

优先打开本轮 `2026-10-20-finished-chapter` 交付目录中的 `雨来之前·样板章.app`，窗口标题为「雨来之前 · 样板章 0.2.1」。选择「从头开始」体验整章。源码可用 Godot 4.6.2 打开本目录的 `project.godot`，或双击 `play.command`。这是独立工程，不读取或覆盖旧游戏存档。

- 方向键或 WASD：连续飞行，八方向等速。
- 按住空格：收拢蜂群并蓄力；出现发光箭头／提示后松开，向当前朝向冲刺。可在蓄力时调整方向。
- 冲刺打开卷叶、撞开干叶帘、击散雨滴；冲进风花会接力加速并转向下一朵。
- 风花的箭头预告真实接力方向；用过一次后花瓣收拢、不再显示箭头。
- 方向提示指向下一组伙伴；带齐伙伴后指向出口。第二段的风花是快捷路线，普通飞行仍可走通。
- 空格过早松开、冲刺撞到厚茎、救援和返回休息点都有明确回应。
- 大叶下可停稳避雨、持续恢复体力；第一次进入记录恢复点，回访也可以休息。
- Esc：暂停；R：返回本段最近的恢复点；M：声音开关。
- 菜单可用上下方向键或 Tab 选择，Enter 确认，也可鼠标点击。

救出伙伴及最后一段的叶下避雨处会记录本次游玩的恢复点。关闭应用后可从当前段落开头继续；标题会明确标注。体力耗尽或暴雨倒计时归零会回到最近恢复点，补满体力并恢复该点计时（至少 20 秒），伙伴不会永久丢失。

体力上限 100，起飞后露天每秒消耗 2，冲刺消耗 20，受雨击消耗 30；救出一组伙伴补充 40，首次借用风花补充 8，叶下每秒恢复 24，均不超过上限。体力条每格 20，蓄力时闪亮的段落预告本次成本，消耗后保留短暂残影。前两段显示旅程用时；最后一段从首次操作起有 55 秒暴雨倒计时，叶下和暂停菜单停止倒计时。结尾显示旅程用时与返回恢复点次数，不设竞速排名。

## 验证

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://verify.gd
godot --headless --path . --script res://ui_verify.gd -- --swarm-qa
godot --headless --path . --quit-after 3 -- --swarm-qa
```

检查退出码、成功标记以及日志中不存在 `SCRIPT ERROR` / `ERROR:`。Godot 有时会在脚本异常后返回 0，因此不能只看退出码。CI 使用独立的 `swarm-flight.yml`，不加载旧年度游戏工程。`verify.gd` 检查完整路线、连续移动、碰撞、雨滴、恢复、体力收支守恒、直接／犹豫路线、暴雨计时及畸形存档；`ui_verify.gd` 通过场景输入处理器传入方向键／空格按下和释放，完成三段与可见结尾，并覆盖 WASD、暂停、失焦、重玩、静音。测试只使用自己的存档文件。

美术统一为少色植物剪纸／套色版画表现，角色、景物和交互状态均由 `world_view.gd` 绘制。此前生成图片的方案收到“AI 感太重”反馈，已从运行资源撤下；现用来源与状态说明见 `asset-manifest.json`。声音为原创 PCM 合成；本轮保留原有音乐、环境音与混音，只补充未蓄足和阻挡等交互音效。运行时无网络下载依赖。桌面包必须 `all_resources` 导出；配置中的独立 bundle ID 应在首次导出时固定。未做 Windows／Linux 桌面包验收。画面按 1280×800 设计，以保比例缩放适配窗口。自动路线和 AI 操作不代表玩家体验通过。

玩法选择与证据记录：[制作说明](../../docs/design/swarm-flight-game-20261020.md)。
