采蜜小店 · MVP {version}

解压后，双击“开始采蜜小店.command”，或直接打开同目录的 .app。
请保持“采蜜小店-MVP”目录完整，不要在压缩包里直接启动。

庭院路牌选择目的地 → 飞入花丛采蜜 → 从入口回庭院 → 找收购员售卖 → 到成长台升级。
本版包含独立蜂巢庭院、两处花地与可绕行/冲刺驱离的蚊子、9个成长节点（共12次升级）和一个储粮目标。
完成储粮后，仍可以继续采蜜。

WASD / 方向键：飞行。
按住 E / 鼠标主键：采集附近花心的花蜜。
庭院左边蜜铺按 E：出售花蜜；中央成长台按 E：成长树；右边路牌按 E：选择地区。
野外入口按 E：返程；池岸右侧花径按 E：去已开放的紫花地。
蚊子察觉时先预警，可绕开或用冲刺驱离；接触会扣续航。
成长树：点击节点查看，点击升级或按 Enter 确认一级。
方向键 / Tab：选择成长；Esc：回到庭院。
空格按住后松开：冲刺。
F：使用已开通的近道。
Esc：保存并暂停。M：开关声音。

应用与启动脚本共用同一份独立采蜜存档：
~/Library/Application Support/BeforeTheRain/nectar_harvest_v1.json
0.19 / 0.20采蜜进度会先保留 .v1.bak / .v2.bak 原字节备份，再升级到新版。
花源/蚊群只在从庭院开始新一趟时刷新，切地区、暂停和读档不刷新。
旧池岸归途存档保持独立。“新的一轮”会先备份当前采蜜进度。
