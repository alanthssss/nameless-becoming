雨来之前 · 采蜜与蜂舞 Demo {version}

解压后，双击“开始采蜜小店.command”，或直接打开同目录的 .app。
请保持“采蜜与蜂舞-Demo”目录完整，不要在压缩包里直接启动。

蜂舞广场选择目的地 → 飞入花丛采蜜 → 从入口回庭院 → 找收购员售卖 → 到成长书屋升级。
本版包含独立蜂巢庭院、两处花地与温和巡游的生物、10个成长节点（共13次升级）和一个储粮目标。
完成储粮后，同伴会在广场庆祝，仍可继续采蜜。
蜂舞转场可按空格跳过；标题/暂停中的设置可简化动画、选择舞蹈和开关声音。

WASD / 方向键：飞行。
按住 E / 鼠标主键：采集附近花心的花蜜。
Q / 鼠标右键：振翅震落蚊子携带的材料，飞近拾取；纤维和树脂用于成长。
庭院左边蜜铺按 E：出售花蜜；成长书屋按 E：成长树；右边蜂舞广场按 E：选择地区。
野外入口按 E：返程；池岸右侧花径按 E：去已开放的紫花地。
生物不会攻击。每朵花采1份，采空后收拢，在所在花地活动18秒后再开；每趟花位有变化。初始续航36，振翅也消耗体力；雨中多消耗，低处叶檐能避雨。花路说明在灯球出发页，完整操作可从暂停菜单查看。
成长树：点击节点查看，点击升级或按 Enter 确认一级。
方向键 / Tab：选择成长；Esc：回到庭院。
空格按住后松开：冲刺。
F：使用已开通的近道。
Esc：保存并暂停。M：开关声音。

应用与启动脚本共用同一份独立采蜜存档：
~/Library/Application Support/BeforeTheRain/nectar_harvest_v1.json
旧采蜜进度先保留对应 .v1.bak / .v2.bak / .v3.bak / .v4.bak 原字节备份，再迁移为v5。v1–v3先按0.23规则缩放旧经济，v4币值与已购成长保留，体力按新上限同比换算，不补发材料。
巡游生物在新一趟刷新；花朵再生按所在花地有效活动时间计算，暂停/切地区/读档不会重置计时。
旧池岸归途存档保持独立。“新的一轮”会先备份当前采蜜进度。
