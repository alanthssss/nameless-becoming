# 合成与消除：一局对照小样

2026-10-20。Alan 明确要求“先做合成和消除两个小样，现有飞行版作为对照。每个都能完整玩一局，规则简单点，做完让我都试试再选方向。”这次制作授权取代此前的小场地救援／连锁解谜候选；那些提案不再进入首轮。用户强调成熟、直接的乐趣，不能为了创新堆系统。Steam Demo 仍不推进。

## 固定范围与选择

负责人 Codex；一个独立 Godot 4.6.2 工程 `prototypes/garden-puzzles`、一个本地 macOS 试玩盒，两款玩法共用选单与基础表现，规则独立。飞行 0.3.0 源码、包和存档保持原样。下一检查点为本轮完成两款可玩包、技术验证和三个明确入口，再由 Alan 整体比较。

| 小样 | 一句话规则 | 完整一局与反馈 |
| --- | --- | --- |
| 合成 128 | 方向键滑动 4×4 棋盘，相同数字合并，合出 128 | 每次有效移动在空位生出 2／4；同块每步只合并一次；达到 128 胜，无合法移动败；支持一步撤回、结算和重玩 |
| 花朵三消 | 交换相邻花朵，三个同类连成一排消除，18 步内消掉 60 朵 | 6×6、五类形状与颜色；无效交换不耗步，下落补充可连消，无解免费重排；达标胜、步数用完败，末步达标优先；结算和重玩 |

合成用方向键／WASD或屏幕方向按钮；消除用点击／相邻拖动，也支持方向键选格、Enter选中与交换。Esc 取消三消选中或暂停，Z 撤回合成，M 静音。输入、动画、计数、结算必须一致，暂停和失焦不能继续提交动作。合成撤回恢复随机状态，重复同一步不会重掷出生格；无效操作不能偷扣步数或改变随机状态。

复用飞行版原创配乐和音效以减少制作变量；图形采用清楚的数字块与五种可区分花形，不为两款另开美术工程。代码表现服从读图，数字／形状不只靠颜色区分。没有成长树、道具、商城、体力等待、联网、外部遥测、Steam上传或商业品质承诺。此轮不新增技能或改工作流工具包。

## 验证与比较

- 两模型：合并一次、四方向、无效输入、满盘／末步结果、撤回随机状态、三连／交叉去重、下落连消、无解重排、合法棋盘与完整终局。
- 模型样本检查策略和种子分布，报告样本条件、完成步数和失败，不把机器人胜率当成好玩。128 与 18步／60朵是本轮初始参数，必要时只依阻断／明显失衡证据修订。
- 真实场景输入：从选单开始，实际键盘／鼠标事件完整完成两款，看到结算并重玩，覆盖暂停、失焦、无效交换、撤回及输入锁；原生渲染与导出包检查。
- 方向判断留给整体试玩：是否容易理解、是否有自己愿意做的选择、是否主动想再玩、哪一段想跳过。不同小样时长与熟悉度可能不同，记录 build／输入方式，不能用通关、强制重玩或自动检查代替偏好。允许保留飞行，也允许两款都淘汰，不预设混合玩法。

## 实施证据

已实现并导出 macOS universal **合成与消除 · 试玩盒 0.1.0**，规则参数保持128／18步60朵。两个入口都包含开局、过程、成功／失败、暂停、重玩和返回选择；原飞行0.3.0为独立对照，未改动其源文件或包。

- 规则检查7442项（写出报告时额外1项，共7443），覆盖边界与128局固定种子模拟；UI事件检查149项，键盘实际滑动77次通关合成、鼠标点击／拖动／键盘14次交换通关三消，结算与重玩均贯通。输局结算使用明确标记的边界夹具，未伪称真人完整失败局。
- 原生渲染同一UI脚本155项（含6张截图保存断言）；1280×800与960×600显示完整。导出包原生启动后实际用方向键合成、点击与拖动消除、暂停返回选单；最终修复包再次完成原生拖动4朵消除、计数4／60、剩17步，返回选单。以上都是开发者自测。
- 只读审查修复两处输入反馈问题：无效交换保留尝试后的棋盘，使返回动画连续；非相邻拖动清除旧选中，避免意外交换扣步。均已增加对应回归。
- 32种子×两策略：合成单步启发式30／32胜、随机合法方向14／32胜，全部局步数中位86／90；三消即时消除最多与随机合法交换均32／32胜，中位11／12步。只说明此小样目标宽松、两款存在完整胜局，不预测Alan难度或好玩程度。
- 打包检查：独立bundle ID `com.alanthssss.gardenpuzzles`，x86_64＋arm64；PCK含运行所需模型／UI／声音，排除验证脚本和文档。声音来源哈希已核对。快速退出时Godot偶有AudioStreamWAV／Playback退出残留警告，无脚本错误；运行、结算和重新开始未受影响，未为此扩展音频改造。
- 独立CI运行导入、规则、完整UI输入路线和主场景；分类器将该独立工程与旧年度游戏／Web工程分开，混合改动仍触发各自检查。分类器对应测试通过；本轮合并前还须取得一次手动全量 Quality gates，实际结果以PR检查为准。
