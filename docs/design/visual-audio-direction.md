# 正式试玩版视觉与音乐方向 v0.1

状态：方向提案，允许通过原型修订；禁止直接批量生产最终资产。

## 1. 设计母题

一句话：**一册会呼吸的四时蜂书。**

玩家看到的世界像由层叠纸片、叶脉、蜂蜡和旧皮革装订而成；蜜蜂、花与失律者保持夸张、清楚、略带幽默的轮廓。危险不靠写实恐怖，而靠比例、节奏、动作和色温变化表达。

## 2. 从 PVZ 借鉴什么

借鉴：

- 一眼可辨的轮廓；
- 造型直接说明行为；
- 可爱与危险同时成立；
- 少读文字也能理解；
- 动画强调蓄力、命中、恢复；
- 音乐随战况加层，而不是频繁换歌。

不借鉴：

- 植物/僵尸的具体比例、五官与表情；
- 草坪格子、卡槽、阳光资源等界面结构；
- 原曲旋律、和声进行、标志性 theremin/音色组合；
- 文案语气、角色命名和笑点。

## 3. 视觉系统不是只有颜色与材质

正式美术需要同时确定以下维度：

| 维度 | 本项目建议 |
| --- | --- |
| 轮廓语言 | 蜂与花圆润、敌害尖锐或失衡；Boss 轮廓先于细节可辨 |
| 比例 | 玩家蜂头胸腹夸张，翅膀承担速度；Boss 比普通敌害至少大 1.8 倍 |
| 视角 | 维持侧俯视单屏，所有交互热点落在清楚平面层 |
| 边缘 | 主体使用剪纸切边；柔软生命用圆弧，失律者用断裂/偏心切口 |
| 材质 | 环境纤维纸、蜂巢蜂蜡、UI 旧皮革；同屏主材质不超过两种 |
| 明暗 | 蜂巢偏暖亮，远花偏高彩，危险区压暗但不丢轮廓 |
| 纹理密度 | 背景低、可交互物中、Boss 高；避免全屏同等颗粒 |
| 描边 | 深色非纯黑描边，粗细随层级，不采用统一像素黑边 |
| 动画语法 | 6～10 帧关键姿态、明显预备动作、短暂夸张形变、快速回稳 |
| 表情/拟人 | 保留昆虫结构，只在眼神、触角、姿态上拟人，不做人形蜂 |
| 图标 | 优先蜂巢、翅、蜜滴、花粉等世界内符号，避免通用科技 UI 图标 |
| 字体 | 标题偏宋/刻印感，数值与操作保持高识别；不牺牲中文 Web 字形覆盖 |
| 特效 | 花粉、蜜滴、纸屑、蜡光四类基础粒子统一构建反馈 |
| 可访问性 | 关键状态同时使用颜色、形状、运动和文字，不能只换季节色 |

## 4. 像素、皮革、剪纸如何取用

### 剪纸：主造型系统

- 负责角色、花、敌害、Boss 和主要环境层；
- 优点是轮廓清晰、适合四季色卡、动画成本可控；
- 风险是过度民俗装饰会压过玩法，必须控制镂空密度。

### 皮革/蜂蜡：界面与蜂巢材质

- 负责 HUD 面板、成长卡、节令册、蜂巢安全区；
- 皮革只做边框和承载面，避免整屏棕色；蜂蜡承担暖色高光与“储存”语义；
- 可随着蜂群状态出现磨损、裂纹、补丁和封蜡变化。

### 像素：辅助数字纹理

- 可用于节气刻度、小图标、花粉闪烁、轨迹采样点；
- 不作为人物主风格，除非未来做完整低分辨率原型并重新制定尺寸、动画帧率、字体和摄像机规则；
- 禁止把高分辨率剪纸角色简单套像素滤镜。

## 5. 四季造型与色卡连接

| 季节 | 五行 | 五音中心 | 造型倾向 | 材质变化 |
| --- | --- | --- | --- | --- |
| 春 | 木 | 角 | 向上、分枝、萌芽、展开 | 纤维清晰、纸层变薄、边缘湿润 |
| 夏 | 火 | 徵 | 放射、膨胀、热浪、群聚 | 高彩纸层、蜂蜡变软、边缘卷曲 |
| 秋 | 金 | 商 | 切割、收束、下垂、结籽 | 金属箔点缀、纸层干脆、纹理锐利 |
| 冬 | 水 | 羽 | 包裹、回旋、凝结、留白 | 半透明蜡层、冷纸、边缘冻结 |
| 蜂巢/季间 | 土 | 宫 | 中心、承载、层叠六边形 | 蜂蜡、旧皮革、压纹纸 |

## 6. 音乐系统

### 6.1 五音不是五个西方大调标签

宫商角徵羽首先作为五声音阶中的结构与主音重心。可以借用固定音级关系（宫、商、角、徵、羽），但不把传统对应机械等同于某个西方 key。每季通过主音、句尾落点、节奏密度、音域和配器形成性格。

### 6.2 建议映射

| 场景 | 五行/五音 | 旋律策略 | 节奏/音色 |
| --- | --- | --- | --- |
| 春季采集 | 木 / 角 | 上行三音动机、句尾开放 | 木鱼轻击、竹/木质拨弦、叶片摩擦 |
| 夏季采集 | 火 / 徵 | 跳进与重复、音域扩大 | 较快脉冲、明亮拨弦、群蜂颗粒 |
| 秋季采集 | 金 / 商 | 下行回应、留出空拍 | 清脆金属点、干燥摩擦、较明确拍点 |
| 冬季采集 | 水 / 羽 | 回旋低音、长尾与留白 | 低频气流、玻璃/冰点、稀疏脉冲 |
| 蜂巢/成长 | 土 / 宫 | 稳定宫音持续音，其他季节动机回归中心 | 蜂蜡般柔和低频、呼吸式节拍 |

### 6.3 动态分层

每个季节不是一条从头播到尾的成品音轨，而是共享拍点的四层：

1. 底层：季节持续音与环境颗粒；
2. 采集层：玩家开始稳定采蜜后加入主旋律；
3. 危险层：敌害逼近、体力降低时加入节奏与不稳定音程；
4. 归巢层：锁定归巢后收束节奏，回到宫/土的稳定音。

Boss 使用对应季节动机的“失律版本”：打乱重音、截断句尾或偏移音高；每完成一次调律，恢复一层正常结构，最终不是打败音乐，而是让它重新完整。

## 7. 首轮原型要求

在生产正式资产前，只做一个 1280×720 代表性画面和一段 60～90 秒动态音乐原型：

- 画面包含蜂巢、玩家蜂、两种花、一种敌害、一个失律者轮廓、HUD；
- 同一构图测试春/冬两套色与材质，验证体系而非画两张不同地图；
- 音乐只做“冬/羽普通采集 → 危险加层 → 归巢/宫”一条完整状态转换；
- 原型通过轮廓识别、信息层级和状态切换后，才扩展到四季与四 Boss。

## 8. 视觉方向原型 v1

![冬季剪纸方向原型](concepts/winter-cut-paper-direction-v1.png)

用途：验证材质与层级，不作为最终资产。

初步结论：

- 有效：暖蜂巢与冷花田的风险分区明确；玩家蜂、花、敌害轮廓可以不依赖文字区分；剪纸与蜂蜡在同一画面中成立；
- 需收敛：皮革 HUD 厚度降低约 30%～40%，避免压过游戏场景；背景花层数减少，交互花与装饰花必须分层；
- 需重做：敌害不能停留在通用“黑红黄蜂”外形，必须按蚊、蚁、蛐、画眉、熊的行为分别设计轮廓；
- 下一版只测试同一构图的春/冬两套色，不增加新 UI 模块，以确认色卡与材质能否跨季稳定。
