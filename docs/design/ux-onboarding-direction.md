# 正式试玩 UX 与首次教学方向 v0.1

状态：首局老师傅因果教学与首次情境教学实施基线。

## 1. 本轮问题定义

试玩反馈确认两个结构性问题：

1. 系统级操作、游戏状态、过程动作和教学说明同时常驻，界面呈现为同权堆砌；
2. 新手体验依靠开场与边栏文字罗列按键，没有“先行动、再理解、逐步掌握”的过程。

因此本轮目标不是换皮或压缩字号，而是重新划分信息层级与出现时机。

## 2. 四层交互模型

| 层级 | 内容 | 出现规则 |
| --- | --- | --- |
| 系统层 | 继续、全屏、声音、退出 | 仅在暂停层出现；运行中只保留暂停入口 |
| 核心状态层 | 携带/目标、体力、蜂巢生命/公共储备 | 运行中可持续读取，但优先附着在蜂身、目标和蜂巢；不得默认等同于三张顶部／右侧常驻卡片 |
| 情境动作层 | 采蜜、惊退、寻迹、归巢 | 只有在动作成立或具有决策意义时出现 |
| 学习层 | 移动、第一次采蜜、第一次归巢、首次机制情境 | 首局按事件依次出现；后续只在机制第一次成立时短暂出现 |

## 3. 首局学习路径

教学状态由玩家行为推进，不由“下一页”按钮推进：

1. **移动**：只提示 WASD、方向键或点击；离开起点一定距离后完成；
2. **采蜜**：先引导靠近仍有蜜的花，进入采集距离后才出现“按住采蜜”；
3. **归巢**：采到第一滴后才介绍 Q/归巢按钮；蜜实际存入蜂巢后完成；
4. **寻迹**：老师傅先示范停稳寻迹；玩家找到并采到真实藏花后才成立；
5. **驱离**：敌害占住资源花，老师傅示范振翅；敌害真实离开资源圈才成立；
6. **急转**：虚线跟随、实线锁定，老师傅向线外急转；玩家须在锁定后同方向连按两次，让冲刺穿过旧位置而自己离开危险通道；
7. **授粉**：老师傅示范同型花间带粉与落粉；玩家让真实受粉花结籽后才成立；
8. **自由行动**：每项模仿成功后撤掉提示，再要求一次真实复现。

当前已实现的老师傅节奏为“示范 → 模仿 → 无提示复现”，并且只接受世界结果，不接受单纯按键。低体力续飞使用一次性情境卡；规则允许饮蜜时，HUD 同时提供按条件显示的饮蜜按钮。投蜜诱饵尚未进入老师傅链。急转采用同方向 0.34 秒内连按两次，同时支持双击目标侧花田；第一次输入会短暂亮起一枚方向标记。

禁止在首屏一次性展示全部按键；禁止用永久底栏代替教学；禁止在玩家尚未遇到敌害时介绍战斗动作。

## 4. 视觉与符号约束

- 蜂群制造、储存及资源系统中的规则多边形统一使用正六边形；
- 自然花朵、叶片和液滴保持有机形态；只有被蜂群标记或激活的自然物才可短暂出现六边形光环；
- 最终表面风格仍在 2026-08-26 门禁中；v3 深色矿物套色推荐已被 Alan 否决。v4 用明亮高明度块面、鲜明功能色、清楚外轮廓和极少内部线统一自然、角色与 UI；v5 再加入活的蜂巢共同体、受控拟人化与角色 IP。两者共用蜂巢／生命／能量的蜂蜡金，以及克制的短虚线／实线／颗粒落地语法；
- UI 材质不得改变信息优先级：装饰纹理低于数值、动作和危险反馈。
- 原始 Alan 自测明确质疑提示集中在最右／最上，并建议简约融入画面。v4 方向稿已用世界内主表达与最小角落查询层替代大顶栏／右栏，形成新的构图假设；它仍待 Alan 审阅，不代表信息内化或该布局已经通过。
- 世界内化不能用“无 UI”制造新障碍：所有阻止结算的条件及进度须从开局可查询，首次控制与无障碍文字须可恢复；区别只在于它们不再承担蜂身、目标、蜂巢和交互结果本可直接表达的内容。

## 5. 验收标准

- 游戏运行时看不到全屏、声音和退出按钮；
- 不存在列出全部快捷键的永久文字条；
- 遮住顶部／右侧说明后，玩家仍能从蜂身、同形目标／寻迹、蜂巢和交互发生处指出携带、下一目标、蜂巢状态与成功／拒绝结果；
- 从开局可查询全部阻止结算的条件及各自进度，世界内化不得产生隐藏门槛；
- 新玩家开始时只收到移动任务；
- 未靠近花时不出现采蜜按钮；
- 未携带花蜜时不出现归巢按钮；
- 每项老师傅示范都冻结真实模拟且不改变资源；模仿后必须撤掉答案并要求一次真实复现；
- 鼠标/触摸和键盘都能完成移动、情境动作、归巢、饮蜜与急转；
- 急转必须表现“跟随虚线 → 锁定实线 → 侧向连按 → 冲刺穿过旧位置”的完整因果，空放动作与无敌帧硬穿均不得算成功；
- Godot 流程测试覆盖真实状态推进、方向急转、寻迹/敌害/低体力首次触发、自动消失与系统层收纳。

## 6. 后续切片

下一轮先验证玩家能否在没有口头解释时复述急转的事实、操作和成功证据。当前正常路线在老师傅连续两次练习后，没有固定的延迟同语法复测机会；未遇到机会不能记为迁移失败。若要验证约 3 分钟后的保持，先提供固定复测切片，再据结果判断是否让普通敌害复用锁线语法。不得以新增常驻面板解决。
