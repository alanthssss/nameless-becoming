# 正式试玩 UX 与首次教学方向 v0.1

状态：冬至首局切片实施基线。

## 1. 本轮问题定义

试玩反馈确认两个结构性问题：

1. 系统级操作、游戏状态、过程动作和教学说明同时常驻，界面呈现为同权堆砌；
2. 新手体验依靠开场与边栏文字罗列按键，没有“先行动、再理解、逐步掌握”的过程。

因此本轮目标不是换皮或压缩字号，而是重新划分信息层级与出现时机。

## 2. 四层交互模型

| 层级 | 内容 | 出现规则 |
| --- | --- | --- |
| 系统层 | 继续、全屏、声音、退出 | 仅在暂停层出现；运行中只保留暂停入口 |
| 核心状态层 | 携带/目标、体力、蜂巢生命/公共储备 | 运行中常驻，但合并为三组而非五张同权卡片 |
| 情境动作层 | 采蜜、惊退、寻迹、归巢 | 只有在动作成立或具有决策意义时出现 |
| 学习层 | 移动、第一次采蜜、第一次归巢 | 首局按事件依次出现；完成后退出本轮教学 |

## 3. 首局学习路径

教学状态由玩家行为推进，不由“下一页”按钮推进：

1. **移动**：只提示 WASD、方向键或点击；离开起点一定距离后完成；
2. **采蜜**：先引导靠近仍有蜜的花，进入采集距离后才出现“按住采蜜”；
3. **归巢**：采到第一滴后才介绍 Q/归巢按钮；蜜实际存入蜂巢后完成；
4. **自由行动**：教学卡消失，寻迹、惊退、诱饵和急转只在其情境第一次成立时解释。

禁止在首屏一次性展示全部按键；禁止用永久底栏代替教学；禁止在玩家尚未遇到敌害时介绍战斗动作。

## 4. 视觉与符号约束

- 蜂群制造、储存及资源系统中的规则多边形统一使用正六边形；
- 自然花朵、叶片和液滴保持有机形态；只有被蜂群标记或激活的自然物才可短暂出现六边形光环；
- 自然环境使用织物/毛毡，生命与能量使用蜂蜡，蜂群设施和 UI 使用植鞣革，运动与联系使用刺绣轨迹；
- UI 材质不得改变信息优先级：装饰纹理低于数值、动作和危险反馈。

## 5. 验收标准

- 游戏运行时看不到全屏、声音和退出按钮；
- 不存在列出全部快捷键的永久文字条；
- 新玩家开始时只收到移动任务；
- 未靠近花时不出现采蜜按钮；
- 未携带花蜜时不出现归巢按钮；
- 完成第一次存蜜后教学卡消失；
- 鼠标/触摸和键盘都能完成三步教学；
- Godot 流程测试覆盖三步状态推进与系统层收纳。

## 6. 后续切片

本轮只解决结构与首次学习。下一轮在此基础上增加“危险首次出现”“体力首次告急”两类短促反馈，并验证冬至安全、探索、危险、归巢四个音乐状态；不得以新增常驻面板解决。
