# 采蜜小店：生活区、地区与遭遇 MVP

NH-RG-v1，2026-11-03。GDD§13.8 → M3 #281–286，整体产品/成本 #211。Alan授权方向，Codex负责设计、实施与内部验证；体验假设不是玩家结论。基线0.20/fdb042d。唯一执行状态在production Now。

## 玩家循环与空间

安全的「蜂巢庭院」→ 到路牌选目的地 →「池岸花丛」采蓝蜜/学习避让 → 穿花径进入已开放的「紫花地」→ 从入口回庭院 → 找收购员交付 → 到成长台改进 → 再出发。

庭院是1280×800的一屏生活场景，没有花源、敌人、天气消耗或自动出发边界。收购摊(300,540)、成长台(640,470)、出发路牌(1020,540)间距足够，100像素内按E交互；三者各自只做一件事。售卖页不再嵌成长入口；成长图保持抽象六边形，关闭回到成长台；路牌列蓝蜜池岸与紫蜜远地，锁定原因、资源、风险和回程方式先于确认显示。已开花地可从路牌直达，近道作为花地内远端回程/跨区捷径保留价值。

每地用独立PackedScene实例，进入时淡出0.18秒、保存提交/替换、淡入0.22秒。转场期间不移动/采集/耗时；清除所有按住键与冲刺；写入失败保持原场景和资源，显示错误。入口不自动传送，须按E；进入后不因按键未释放反弹。退出游戏只保存稳定场景状态。生活补满续航；野外互换不回血。

## 分区规则与节奏

保留原14个花簇坐标/库存、价格/成长ID/效果，减少同时呈现的杂物。池岸独立范围x400–1720，紫地x1840–3520；逻辑世界坐标继续用于旧档转换，不让玩家横穿未加载的空白。池岸入口(470,575)、通紫地花径(1660,575)，紫地入口(1900,575)。同一入口在池岸提示回庭院，在紫地提示返回池岸；紫地另提供回庭院选择，避免强制空跑。新趟从庭院出发才增加trip_index并刷新所有花源和种群；区域之间往返不补货、不加趟数、不重置敌人。已有F近道两端(1040,400)/(3000,400)保留，穿行同样经过转场并保留续航/货物。

初次池岸可安全采满第一囊：第一簇和入口无敌人。中段可看到一只巡游蚊，玩家可绕开、诱导后采花或冲刺驱离。紫地提高单蜜价值，出现两只较警觉蚊与既有细雨/遮蔽；高价值不强制击杀。不新添货币、掉落装备、血条或支线任务；战斗的回报是清出本趟安全采集空间。

## 种群与遭遇：本项目参数，不是Shelldiver公开算法

每个新趟根据trip_index从预先审核的锚点组合选择，完全确定、可复现。池岸上限1只巡游蚊；紫地上限2只警戒蚊。入口和池岸出口半径220内不生成/追击，首簇不放敌人。限定活动区，绝不在玩家身上、生活区或切入画面时凭空补怪；种群在出发生成，未加载区冻结。

状态：巡游 → 察觉预警0.65秒 → 有限追击最多2.2秒 → 返回锚点；脱离活动半径或安全入口立刻脱战。巡游蚊追速145，警戒蚊185，均低于玩家230；警戒范围145/175、活动半径190/230。接触扣续航8/12，全局受击保护1.5秒；不直接吞货，耗尽仍按原救援损失一半未售货物。准备动作、预警符号、冲刺方向、受击闪烁和驱离动画必须可读。冲刺中接触优先驱离，不能同帧还扣续航；本趟驱离后不重生，无敌人死亡奖励，防止刷怪货币循环。花源与敌人状态必须随存档保存，暂停/切区/冷续不重置；持续伤害、重复撞击和安全区穿越需定向测试。

### 生成机制：哪些能推导，哪些不能声称知道

官方截图的浅海100米入口有潜艇、开放水域中的水母；沼泽与晶洞使用隧道/空腔，生物与可拆材料形成不同空间分布；火山区画面出现大范围红色预警。静帧只证明当时位置与视觉，不能证明碰撞、触发半径、每分钟刷新量或敌人AI。

公开资料没有给出生成器代码、随机种子、活跃上限、首次填充规则、死亡后补怪时间、离开/读档是否重置或离屏回收算法。论坛里“重访同深度布局不变”的描述只是玩家证词，未作为实现规格。四群系×三层、具体Prestige解锁数字也没有在本轮一手材料中充分核实，不写成确定规则。

可以借鉴的设计关系是：**地区决定候选内容，地形给它们合适的位置，资源供给支撑下一项升级，危险改变采集方法**。这是我们的分析归纳，不是宣称Shelldiver内部采用某个具体算法。对应实现用固定ID、少量审核锚点、每趟有限种群；目前不需要通用随机刷怪器、波次导演或按玩家实力自动变难。

### 场景切换怎样服务节奏

岛屿与海域的职责差别是可观察事实；我们选用的淡入淡出时长、入口半径、直接返家、两区邻接图均是本项目决定。转场承担三个作用：告知地点变化、切换安全/风险规则、形成“这趟结束/下一趟开始”的资源边界。不能只播放黑屏而仍让野外敌人追进家，也不能把暂停当成新的一趟。

庭院中玩家以“货物→金币→成长→目的地”作短准备，三个点均在一屏内；不要求每次去所有点。空手可以出发，没钱可以直接再采，钱够也可以暂不买。野外入口始终允许撤退，不要求清敌或采满；成长解锁只影响紫地资格，池岸基础收入始终可用。近道仍连接池岸中段与紫地远端，适用于远处满载返程和快速抵达后半部，避免直达选区后变成无价值购买。

### 两区节奏与扩展方式

池岸第一花簇靠近返程点，前半部安全，让玩家先看到第一囊及第一笔售卖；巡游蚊在后半部提供一次看见预警、绕行或冲刺的练习。紫地首先提供安全入口和一簇紫蜜，再遇到警戒蚊，后部把细雨与叶棚叠加；同时数量受限，不用连绵追击覆盖整个采集过程。敌人不会随着拥有更多成长无限增强，否则成长的效率回报会被抵消。

后续若扩第三地区，先定义一种新资源去向、一种新空间选择或一种新生物对策，再选择两者是否组合；每个新地区至少保留安全入口/撤退与一个休息观察段。此前只是每趟小规模采蜜MVP，不将重复出行次数称为多个关卡，也不声称已经完成Shelldiver的体量。
