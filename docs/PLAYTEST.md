# 《无名：成蜂》试玩证据与记录

本文件管理三条不能互相替代的证据流：Alan 本人自测、未参与策划／开发的外部玩家试玩、真实 Windows 设备检查。同一人在真实 Windows 设备上的外测可以同时产生两类记录，但结论仍要分别汇总；开发者自测永远不能计入外部玩家样本。

2026-08-21 的两分钟选择题问卷已被本轮证据包取代。旧问卷把预设的紧张点、正确行为和机制名塞进选项，只能测“玩家是否同意选项”，无法证明首分钟实际发生了什么；原来的 `3/5` 主动撤离与重开比例也不再作为当前版本的单一通过门槛。

## 生成一次匿名证据包

在与候选构建对应的仓库提交上执行：

```bash
npm run playtest:prepare -- \
  --task A \
  --candidate-commit <游戏内显示的提交号> \
  --candidate-clean \
  --artifact-sha256 <发给玩家的安装包 SHA-256>
```

默认输出到 `outputs/playtest-evidence/<随机会话号>/`，每位参与者单独生成一包，不覆盖上一位。生成器会从候选提交中的 `package.json` 读取版本，验证并保存完整提交号，同时记录当前工具提交和 dirty 状态。使用 `--candidate-commit` 时必须显式二选一：CI／固定 artifact 用 `--candidate-clean`；确实来自未提交工作区的候选才用 `--candidate-dirty`。若省略候选提交，则直接使用当前 `HEAD` 及其真实 dirty 状态。安装包 SHA-256 必填，但生成器只记录这项绑定声明，不读取或计算安装包；协调者必须先用 sidecar 或本机哈希工具确认它与玩家实际收到的文件一致。

输出严格分成两部分：

- 只把 `participant/` 文件夹交给参与者，其 `index.html` 无网络依赖，可在本机保存并导出匿名 JSON；
- `coordinator/` 只给 Alan／测试协调者，包含交付步骤、构建清单和内部分析模板；参与者页面不会链接或加载它。

输出目录带专用 sentinel。生成器只会替换自己创建的目录，拒绝仓库、源码目录、文件系统根目录和没有 sentinel 的现有目录。

## 三种互不混做的任务包

### A：首次体验

- 每位未参与开发的玩家只从标题开始玩首节点，T0 为首次取得控制权，最多 15 分钟；
- 开始前不解释操作、目标或设计意图。玩家明确求助后可给最少必要帮助，但必须记录其求助原话和相对时间；
- 核心记录首分钟、第一次交蜜、完成条件、传粉、急转、饮蜜、失败与重开；
- 每一项先选接触状态：未到达、到达但未注意／未尝试、尝试未完成、借助游戏内提示完成、经游戏外帮助完成、独立完成；
- 选择“未到达”后理解题自动隐藏，不能把未遇到误算成没看懂；
- 当前正常首轮路线没有稳定的“三分钟后再次急转”机会。本轮只问是否自然遇到复测机会；没有机会必须记作构建未提供机会，不能判成迁移失败。

参与者只回答不泄题的自由回忆，例如：

- “你当时觉得这段什么时候会结束？你从画面哪里看出来的？”
- “刚才敌害冲过来时，你觉得发生了什么？如果再遇到一次，你会怎么做？”
- “关于花、蜜蜂身上的东西和花后来的变化，你记得发生了什么？”
- “你注意到体力变化时做了什么，或者本来想做什么？”

### B：单个高级切片（当前阻塞）

每人只测一个季节机制切片或一个 Boss 的原则保留，但当前正式游戏固定从首节点开始，没有可复现的单切片入口。`--task B` 因此会明确拒绝生成，不能让玩家先跑大量前置节点来冒充独立切片测试。

只有在另一个任务提供并固定“单切片构建或存档入口”，且该入口与同一候选提交、artifact 和哈希绑定后，才能开放 B 包。参与者只应看到中性切片编号；真实季节／Boss 映射只留在协调者清单。

### C：独立音乐盲听

音乐不与 A/B 长流程捆绑。继续单独执行 `npm run audio:review`，且只把 `outputs/music-blind-review/listener/` 给听者；季节、用途与配对答案仍留在隔离的 `reviewer/`。

## 时间、原话与隐私

- 所有事件时间都是 `T+mm:ss`，其中 `T0 = 首次取得控制权`。远程无观察、无录像或玩家不记得时选择“时间不可得”，不得伪造精确秒数；
- 参与者导出只含构建来源、匿名代号、设备类别、接触状态、相对时间和自由回答；
- 协调者收到 JSON 后，在内部模板中分栏保存：客观观察事实、玩家逐字原话、开发者解释、后续行动。不得把玩家原话润色成开发者结论；
- 不收姓名、联系方式、账号、IP、年龄、性别、精确位置、健康／残障信息、脸或声音；
- 若参与者自愿匿名录屏，必须先说明用途，允许关闭麦克风并裁掉通知。录屏引用只留在内部分析，不进入参与者表单。

## 当前证据状态与判定

当前外部玩家样本仍为 **0**。生成器、JSON、CI 或 Alan 的方向批准都不增加样本数。

首轮先收集 3–5 名陌生玩家的 A 包，再按真实失败簇决定是否制作固定 B 切片入口。人数不是 1.0 的唯一门槛；至少还要分别关闭 Alan 完整人工流程、Windows 真机、音乐盲听、构建和发行链路。只有在同一固定构建上取得足够可比较记录后，才能讨论教学理解率、节奏、重开意愿或版本通过。
