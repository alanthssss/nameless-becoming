# 《无名：成蜂》MVP 试玩记录

本文件只记录未参与策划者的真实试玩。开发者自测不能替代外部试玩，也不能预填结果。

## 统一流程

1. 不解释操作，让试玩者从标题画面自行开始；
2. 记录首次采蜜、首次归巢和首次失败的时间；
3. 不提示“应该撤退”，观察其是否主动放弃远花；
4. 首局结束后不催促重开，记录其是否主动开始第二局；
5. 试玩结束后只问下列固定问题，避免诱导答案。

## 通过门槛

- 5 名试玩者均未参与策划；
- 至少 3 人主动放弃远花并归巢；
- 至少 3 人失败后主动开始第二局；
- 每人均留下首次归巢时间、失败原因、最紧张与最困惑时刻。

未填满且未达到门槛前，版本只能称为“0.9 候选 MVP”，不能标记为 1.0 MVP。
