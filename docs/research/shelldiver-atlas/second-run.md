《采蜜》的对应观察是，一项能力改变每个动作的产出时，玩家可能更早满囊；容量成长帮助玩家利用这项能力的条件，可以用路线中的首个满载点判定。成果还可落到玩家以前见过的地方，让玩家走近并互动完成最后一步。以上为本作假设。
