# 《归巢之前》Godot MVP 规格

状态：范围冻结（MVP 0.4–0.9）  
目标体验时长：首次通关 15～25 分钟  
目标平台：macOS、Windows 单机  
核心问题：玩家是否会因为“再采一朵”的诱惑承担风险，并在撤离成功后愿意继续下一节令？

## 1. 一句话体验

玩家控制一只离巢蜜蜂，在逐渐失衡的四个节令中寻找花蜜、对抗生态威胁，并在体力耗尽前带着收获归巢；每次归巢都要选择蜂群接下来如何生存。

## 2. 完整玩家流程

```text
标题界面
→ 30 秒内学会飞行、采蜜、蜂针和归巢
→ 春分：低压采集
→ 蜂巢：第一次成长选择
→ 夏至：蚊群高压
→ 蜂巢：第二次成长选择
→ 秋分：资源稀少与路线选择
→ 蜂巢：第三次成长选择
→ 冬至：资源与体力双重压力
→ 失律之蚊遭遇
→ 四季结算
→ 再来一次
```

## 3. 三个设计支柱

### 3.1 贪与撤

- 稀有花位于更远或更危险的位置；
- 采蜜需要持续停留，不能碰触后瞬间获得；
- 携带资源只有回到蜂巢才安全；
- 体力、敌人和路线共同制造撤离压力；
- 失败损失本次携带资源，但不立即清空整局进度。

### 3.2 蜂群而非孤胆英雄

- 玩家带回的蜜进入蜂群公共储备；
- 节令间只能从三种蜂群成长中选择一种；
- 成长体现分工：飞行、采集、守卫；
- 结局评价蜂群是否熬过循环，而不只计算击杀数。

### 3.3 节气与阴阳消长

- 四个 MVP 关卡分别代表春分、夏至、秋分、冬至；
- 色彩、花量、敌人、能耗与音乐密度连续变化；
- 每关使用同一套操作，不制作互不相关的小游戏；
- 顶部保留二十四节气路线，为后续每季六关扩展。

## 4. 核心操作

| 动作 | 输入 | 作用 | 成本/限制 |
| --- | --- | --- | --- |
| 飞行 | WASD / 方向键 / 鼠标目标 | 在花田移动 | 持续缓慢消耗体力 |
| 采蜜 | 按住空格 | 从附近花朵逐滴采集 | 停留、额外消耗体力 |
| 振翅 | Shift | 快速位移、脱离包围 | 高体力消耗 |
| 蜂针 | J | 击退或眩晕近身敌人 | 体力消耗、冷却 |
| 感知 | E | 短暂显示花蜜、敌人与归巢方向 | 冷却，无伤害 |
| 暂停 | Esc | 暂停并显示操作 | — |

## 5. 关卡内容

| 关卡 | 教学/压力 | 花田特征 | 敌人 | 目标 |
| --- | --- | --- | --- | --- |
| 春分 | 学习与建立信心 | 普通花多、路径短 | 少量蚊虫 | 完成两次安全归巢 |
| 夏至 | 高收益与高威胁 | 稀有花多、危险聚集 | 蚊虫 + 掠蜜蚁 | 在追击中完成目标 |
| 秋分 | 匮乏与规划 | 花少、距离远、枯花干扰 | 掠蜜蚁为主 | 控制路线和体力 |
| 冬至 | 生存极限 | 霜花少、体力衰减快 | 两类敌人 + 寒风区 | 保住足够蜂群储备 |
| 失律之蚊 | 首个主题遭遇 | 圆形巢外空间 | Boss 三阶段 | 调律或驱离，而非单纯击杀 |

### 普通敌人

1. **蚊虫**：感知范围内直接追击，接触后损失体力和少量携蜜；蜂针可眩晕。
2. **掠蜜蚁**：移动较慢，优先追逐掉落或携带的蜜；被击退后会绕路再次靠近。

### 失律之蚊

主题：只索取、不流转。  
玩法：玩家通过蜂针打断吸取、引导其撞入花粉团并回收被夺蜜量，完成三次“调律”。胜利条件不是削空传统生命条。

## 6. 蜂巢成长

每个节令结束后展示三选一，只在本局有效：

- **长翼蜂**：基础飞行速度 +10%，振翅消耗 -15%；
- **采蜜蜂**：采蜜间隔 -15%，单朵花额外保留 1 滴；
- **守卫蜂**：蜂针范围 +18%，冷却 -15%。

同一路线可以重复选择两次，形成基础构筑；MVP 不增加装备栏、稀有度或商店。

## 7. 状态与存档

- 自动保存：音量、窗口模式、语言预留、教程是否看过、最佳结算；
- 不保存进行中的局，退出视为结束当前循环；
- 提供“新循环”“继续本次启动中的循环”“设置”“退出”；
- MVP 无账号、云存档和联网功能。

## 8. 反馈与可读性

- 采蜜：花朵收缩、花粉粒子、音高递增；
- 受击：短暂闪白、屏幕震动、蜜滴飞散；
- 危险：敌人靠近时环境声与边缘暗角增强；
- 归巢：携蜜飞向蜂房、储备数字滚动增加；
- 节令变化：调色连续过渡，而非硬切主题皮肤；
- 所有关键状态同时使用颜色与形状表达，不能只依赖色觉。

## 9. MVP 验收标准

### 可玩性

- 新玩家不阅读外部说明，60 秒内完成第一次采蜜和归巢；
- 从标题开始可完整经历四节令、一次蜂巢成长和 Boss 结算；
- 正常一局 15～25 分钟；
- 不存在无法继续、无法撤离或资源必然不足的状态；
- 键盘和鼠标均可完成整个流程。

### 技术

- Godot 4.6.2 启动与主场景无脚本错误；
- 关卡、敌人和成长数值来自外部数据；
- 自动检查覆盖数据结构、场景加载和核心公式；
- 目标机器持续达到 60 FPS；
- 可导出 macOS 与 Windows 调试包；
- GitHub 的 `main` 始终保持可运行。

### 试玩

- 至少 5 名未参与策划的人试玩；
- 至少 3 人在一次出巢中主动选择放弃远花并归巢；
- 至少 3 人失败后主动开始第二局；
- 记录首次归巢时间、死亡原因、最紧张时刻和最困惑时刻。

## 10. 明确不做

- 二十四个完整关卡；
- 四个完整 Boss；
- 开放世界、地图传送与支线任务；
- 装备、背包、品质、抽卡、商店和货币体系；
- 大量剧情对白与完整配音；
- 联机、排行榜、账号、付费与广告；
- 最终商业美术；
- 手机正式适配。
