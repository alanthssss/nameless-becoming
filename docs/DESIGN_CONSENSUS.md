## 二、当前操作循环

```text
飞离主巢
→ 寻找并持续采蜜
→ 体力、敌害与当组机制改变路线
→ 继续采 / 惊退 / 诱饵 / 急转 / 饮蜜 / 撤回
→ 在巢门站稳并卸蜜
→ 满足所有已列条件后立即结算
→ 蜂群成长 / 下一节点 / 失律者
```

当前输入收敛为移动、情境动作、归巢、饮蜜和急转。饮蜜已有按条件显示的鼠标／触摸入口；1280×720 是 HUD 参考画布，1920×1080、1440×900 与 1024×768 的等比安全框已经自动验证。该实现不是任意宽高比的世界重排或手机正式适配，真实原生触屏仍待设备验证。

### 教学共识

- 首节点依次覆盖出巢归巢、寻迹、惊退、急转和授粉；首次采蜜明确要求贴近花心、持续按住，并以“蜜囊 +1”作为松手证据；
- 每项采用“示范 → 模仿 → 无提示实践”；
- 寻迹必须找到并采到隐藏花，惊退必须让敌害真正退出资源区；
- 急转必须在锁线后从锁定位置附近双击同一可行轴，并在敌害穿过旧位置时已经离开真实危险通道；
- 单纯按键、锁线前抢跑、空地双击或靠无敌帧硬穿都不能算教学完成；
- 普通敌害尚未持续复用锁线语法；当前正常路线在老师傅连续两次练习后没有固定的延迟同语法复测机会。未遇到机会不能记为迁移失败；若需要验证约 3 分钟后的保持，先提供固定复测切片，再据结果决定是否让普通敌害复用锁线语法。

## 三、24 节点与四组行为

| 组 | 当前实现 | 明确废止的旧描述 | 真人待验证 |
| --- | --- | --- | --- |
| 春／授粉 | 开放花药取粉；蜂身松散散粉；同型开放柱头受粉后结籽；每节点 2 次 | 久不采休眠、低蜜量触发新花、携粉碰闭合花苞立即开花／回蜜 | 不看文字能否分辨器官并复述因果 |
| 夏／袭扰 | 第一次真实卸蜜触发有翅劫掠者；其移动、偷蜜、持赃，玩家逐只惊退后蜜落回 | 定时弹出“巢口／花区告急”、不响应无后果的文字事件 | 是否真的打断原路线并主动改线 |
| 秋／留种 | 最后一滴前强制松手；继续采尽或留下种核，真实归巢后结籽并增储备 | 只有季末“储备冬蜜 vs 哺育幼虫”滑块代表整季玩法 | 是否理解两种可见后果并做主动选择 |
| 冬／暖点 | 寒区降温减速；携蜜依次点亮 3 个蜂蜡暖点，逐段开放远花路线 | 仅靠体温条、回巢耗储备和侦察冷却表达抱团 | 是否因暖点顺序与活动半径改变路线 |

秋段末的公共储备／哺育幼虫分配仍是已实现的跨季投资，但它是留种之后的附加层，不得再被写成秋季唯一玩法。

## 四、四位失律者

共同收束是：满足独立暴露条件，进入短暂可调律窗口，在共鸣实体附近用震翼登记 1 次；共 3 次。每阶段更快、窗口更短，巢口照料最多 2 次。

| Boss | 暴露条件 | 独立读取 |
| --- | --- | --- |
| 失律之蚊 | 完成一次真实吸取 | 吸取结束与饱食窗口 |
| 失律之油葫芦 | 跳跃落地 | 落点、停顿与窗口 |
| 失律之画眉 | 寻迹揭出真声 | 假回声与真身分离；后续假回声增加 |
| 失律之熊 | 玩家闪过锁线冲锋，熊撞上暖息花 | 冲锋旧位置、暖花碰撞与眩晕 |

旧的“只有失律之蚊已实现”“其余 Boss 分配待定”以及“四位都只是引到花粉团连续按三次”均已过时。

- 主体使用布艺贴花的清楚轮廓，毛毡控制体积，蜂蜡／浅色植鞣革／刺绣分别表达生命能量、蜂群设施和信息轨迹；剪纸是已撤回候选；
- 低噪地表、独立蜂巢、8 种季节花和世界实体已进入构建；
- 常驻空圈已由花药／柱头／结籽体、种核／破裂种荚、蜂蜡暖点替换；短暂寻迹和攻击范围线仍可在动作发生时显示；
- 这些是实现事实和快照证据，不是 Alan 已逐项通过画风或外部玩家已读懂。
