# 游戏色彩体系 · 二十四节气阴阳消长色系

> 参考色卡：二十四节气 · 阴阳消长色系  
> 核心逻辑：以影子长度的阴阳比例（两至两分为正色），在四个正色之间渐变过渡。  
> 当前映射：四正色（玄 / 青 / 朱 / 白）是 24 个数据节点之间的色彩锚点，不是“4 大关 × 6 小关”的现行关卡规格。`seasons.json` 中春分、夏至、秋分是 3 个显式 Boss 节点；大雪后由状态流进入冬至失律之熊。本文只定义色彩过渡，不改写这一推进结构。

> **2026-08-26 显示层二次纠偏：** Alan 已先后否决 v3 的偏暗、偏脏、低对比与线噪，也否决 v4／v5 的明暗两极、脏色、半照片转手绘、无感情色彩、无效细节、缺乏合理艺术抽象和跨画面风格断裂。下列玄／青／朱／白只保留为季节数据与叙事锚点，**不得直接铺成全屏主色、滤镜或 UI 大面板**。当前没有通过的显示层调色板；“干净”不等于一味提亮，“有情绪”也不等于大面积压暗。

这 8 色曾是 v4 概念与灰盒的候选功能色，但其对应视觉执行已经被否决，**不得继续称为当前候选或直接套入资产**。表格只用于说明当时试图建立的功能分工；具体色相、明度、饱和度与面积比例必须在新的统一主样帧中重新建立。季节可以改变地表、光温、生态密度和辅助色，但玩家蜂、蜂巢节点、即时危险及关键器官必须保留稳定识别，不得被季节主色染成同一片。

下一轮色彩先通过以下守栏：全图保持稳定中间调，近黑、近白与高饱和色只作受控强调；禁止整图高曝、大片闷黑、褐灰脏滤镜和全局蓝橙对冲。首张主样帧可暂以中间调约占 60%—75%、近黑与近白各不超过约 10%、高饱和面积不超过约 15% 作开发启发式，待 Alan 通过样板后再校准，不把比例误写成艺术定律。

## 一、色彩哲学与游戏主题

《无名：成蜂》的核心张力是"再采一朵，还是现在归巢"。四季不是简单的背景切换，而是蜂群生命节奏的四个相位：

- **春 · 玄→青**：蛰藏中苏醒，从混沌的深色泥土走向新绿。学习、试探、低威胁。
- **夏 · 青→朱**：生机最盛，也是竞争最烈的时刻。高压、繁茂、风险与回报俱增。
- **秋 · 朱→白**：热烈收敛为清冽，花蜜匮乏，必须做出取舍。
- **冬 · 白→玄**：冷寂、极限、彼此需要。黑暗重新吞没世界，但蜂巢内部的光亮更重要。

四色同时构成一套**可读的视觉语言**：玩家不必看 UI，仅凭画面色调就能感知当前处于四季循环的哪一段。

## 四、功能色分配

本节保留功能分工，但不再代表 v4 画风获准。四正色只调节季节气氛，不能直接覆盖稳定功能色；具体数值须在统一主样帧、真实尺寸、灰度和色觉弱化测试后重新冻结。

### 环境 / 场景

| 元素 | 用色规则 | 示例 |
|------|---------|------|
| 远景／边缘生态 | 当前节点锚色轻量混入叶绿／冷影 | 不得用玄色渐变压暗整屏；边缘可更冷、更密 |
| 可玩地面／土壤 | 高明度季节基底 + 暖白路径 | 春以 `#BFE36B` 为候选；冬也保留清楚冷亮地表 |
| 花田／可采集物 | 物种稳定功能色，季节只改变叶色、光温与密度 | 白／珊瑚／紫等大色组，不能全染成青灰 |
| 返蜜花 | 蜂蜡金 + 原花型轮廓 | `#FFC83D` 状态点，不用纯色光圈 |
| 蜂巢安全区 | 蜂蜡金／琥珀 + 暖白地面 | `#FFC83D`／`#ED8B24`／`#FFF4D6` |
| 危险／警戒 | 珊瑚红为即时危险，深紫为失律／未知 | `#E65353`／`#6D3E83`，同时配形状与动作 |

### UI

| 元素 | 用色 |
|------|------|
| 查询承载面 | 暖白 `#FFF4D6` |
| 文本／轮廓 | 炭蓝 `#263840` |
| 主动作激活 | 蜂蜡金 `#FFC83D` 或叶绿 `#3F824C`，按语义分工 |
| 危险／取消 | 珊瑚红 `#E65353`，不得兼任普通悬停色 |
| 文本辅助／禁用 | 炭蓝降低不透明度，并保持可读对比 |
| 进度／资源 | 与世界实体同形、同色；蜜用蜂蜡金，花粉沿用类型形状色 |
| 失律／未知 | 深紫 `#6D3E83`，不与即时受击混为一色 |

### 角色与特效

| 元素 | 用色 |
|------|------|
| 玩家蜜蜂 | 主体色与翅色待角色继承表和统一主样帧确认；保持稳定辨识，不受季节整体彩染 |
| 普通敌人 | 保留物种固有色，危险部位用珊瑚红或深紫局部锚定 |
| 失律者 / Boss | 物种本色失衡 + 深紫／珊瑚局部状态，不做全身朱黑皮 |
| 采集粒子 | 花型色到蜂蜡金的短促颗粒 |
| 受伤／受击 | 珊瑚红脉冲 + 形变／声音 |
| 归巢引导 | 暖白／蜂蜡金短促边缘指向，不画常驻长线 |
| 节气过渡粒子 | 从上一节点色渐变到下一节点色 |

## 五、材质与纹理原则

色谱只规定色彩关系，不替某种表面材质背书。2026-08-26 已重新打开最终画风门禁；“布艺贴花主体、毛毡微缩体积、浅色植鞣革 UI”、v3 深色矿物套色以及 v4／v5 的地图／海报执行均降级为历史生产假设或否决对照。下一轮必须先用同一代表帧统一形状抽象、轮廓、明暗档、纹理尺度、光源与有限色，再从该母版派生实机、地图、立绘和海报。在 Alan 明确确认前，任何色表都不能写成最终规范。宣纸、剪纸、像素或其他早期提案不因出现在参考色卡中而自动恢复。

1. **干净不等于高曝，情绪不等于压暗。** 用受控大色面、有限明暗档和一致投影提供层次；蜂蜡透光只出现在状态成立处。
2. **颜色边界必须保持交互轮廓清楚**，不用模糊扩散吞掉花器官、敌害和机制实体。
3. **背景低噪，交互层对比充足。** 低饱和氛围不等于全屏低对比。
4. **UI 与世界共用轮廓、功能色和反馈语法。** 暖白、炭蓝和蜂蜡金的具体数值仍待主样帧重建；不再使用大块深靛顶栏／右栏，也不另做与世界割裂的办公面板或像素皮。
5. **粒子和光晕只表达状态变化**，不作为遮盖可读性的常驻装饰。
6. 详细生产约束以 [`design/ART_IMPLEMENTATION_STANDARD.md`](design/ART_IMPLEMENTATION_STANDARD.md) 为准。

## 六、技术实现速查

Godot 4.x 中直接使用 `Color8(r, g, b)`：

```gdscript
const PALETTE := {
    "xuan" = Color8(16, 20, 32),      # 玄
    "qing" = Color8(0, 128, 128),     # 青
    "zhu"  = Color8(220, 60, 60),     # 朱
    "bai"  = Color8(245, 245, 245),   # 白
}
```

节点色调可通过 `CanvasModulate` 或后处理渐变覆盖实现；粒子与 UI 优先使用调色板常量，避免硬编码色值。
