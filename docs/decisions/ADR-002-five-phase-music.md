# ADR-002：四季、五行与五音音乐骨架

状态：提案，待声音原型验证

## 背景

四季自然对应木、火、金、水，但传统五行和五音还包含土与宫。若强行把五项压进四季，会丢失一个中心或制造不自然的季节归属。

## 决策

- 春/木/角、夏/火/徵、秋/金/商、冬/水/羽；
- 蜂巢、成长和季间过渡承担土/宫；
- 五音作为旋律重心与句法，不机械等同于五个西方调号；
- 每季音乐采用底层、采集、危险、归巢四层动态结构；
- Boss 使用季节动机的失律版本，调律过程逐层恢复结构。

## 理由

蜂巢本来就是资源回归、成长与安全的中心，土/宫作为中央承载与稳定音有明确玩法语义，也让四季音乐拥有共同归宿。

## 后果

- 现有四季程序化旋律可作为技术底座，但需加入情境状态接口；
- 首个声音原型选择冬/羽→危险→归巢/宫，验证动态切换和情绪是否成立；
- 正式配器和节奏审美仍需要用户提供音乐参考。
