# ADR-001：PVZ 参考边界与视觉系统

状态：已修订（2026-08-26）；剪纸与深色矿物版绘推荐均已撤回

## 背景

用户喜欢初代《植物大战僵尸》的美术与音乐，同时提出像素、皮革、剪纸三种视觉概念。2026-08-26 又明确否决当前推荐图的暗、脏、低对比配色和杂乱线条，并要求从 PVZ 寻找干净、明亮、对比清楚的样式灵感。需要形成原创、可执行且不会拼贴失控的参考边界。

## 决策

- 参考 PVZ 的**功能可读性**：安静而统一的背景色面、交互物的高局部对比、功能先于装饰的轮廓、动作的预备／发生／结果，以及少文字、避免视觉噪声、用造型教规则；
- 当前候选转为“明亮生态动画 × 蜂巢地标”：高明度大色面、受控鲜明色差、清楚外轮廓、极少内部线和一致软阴影；蜂蜡金只强化蜂巢核心、蜜、花粉和状态结果，不再以深靛大面板、橄榄旧化或满屏矿物颗粒建立项目身份；
- 不复制具体植物／僵尸、五官、比例、草坪格子、平行路线、卡槽、阳光、铲子、界面、字体、文案、旋律、编曲和标志性音色；
- PVZ 只提供读取方法，不提供本项目的地图拓扑。扩大地图和蜂巢“类似篝火”的决定来自本项目自身的归巢循环，详见 [`../design/map-evolution.md`](../design/map-evolution.md)；
- 织物／毛毡、植鞣革、刺绣与矿物版绘均降级为历史实验或可选局部质感，不再是全屏必须模拟的材质系统；
- 剪纸仅保留为已测试、近乎淘汰的历史候选，不作为后续资产生产基准；除非用户重新明确启用，否则不得据此生成或接入资产；
- 像素仅作为辅助数字纹理，除非未来另立完整像素原型；
- 先做一个代表性画面验证，再决定是否批量生产。

## 理由

2026-08-20 曾以低成本动画与强轮廓为理由提出剪纸主系统，但当日实际同时生成了毛毡立体场景、缝制布艺贴花和纸片等多张候选。归档时只提交了纸片图，使候选方向被误读为最终决定。用户随后确认剪纸已近乎抛弃，因此撤回该结论。

2026-08-26 的 v3 “矿物色套色版绘 × 局部蜂蜡”又因橄榄／芥黄／深靛整体偏暗偏旧、满屏颗粒和线条争夺注意力、固定左巢右险与大面板构图不符合后续大地图而被 Alan 明确否决。参考 [EA 官方原版截图](https://www.ea.com/games/plants-vs-zombies/plants-vs-zombies)可见的高明度统一场地、清楚角色色块和强焦点层级，以及 [George Fan 的 2012 GDC 分享](https://media.gdcvault.com/gdc2012/slides/Design%20Track/Fan_George_How%20I%20Got.pdf)中“少文字、避免噪声、用视觉教规则”的方法，可以直接修正上述问题；但草坪拓扑、角色造型和 UI 不是可复制目标。

## 后果

- 后续资产必须说明轮廓、色块、明度层级和动画功能；
- 禁止用像素滤镜把现有矢量资产伪装成像素风；
- 下一张代表性画面优先验证明亮、干净、高对比、低线噪与蜂巢节点构图；深色矿物推荐图只保留为否决对照；
- 历史纸片图必须标为“淘汰候选”，不得单独展示成当前方向。
