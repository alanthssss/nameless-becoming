# ADR-001：PVZ 参考边界与材质系统

状态：已修订（2026-08-24）；剪纸主造型决策撤回

## 背景

用户喜欢初代《植物大战僵尸》的美术与音乐，同时提出像素、皮革、剪纸三种视觉概念。需要形成原创、可执行且不会拼贴失控的方向。

## 决策

- 参考 PVZ 的功能可读性、强轮廓、幽默与危险并存、动态音乐原则；
- 不复制具体角色、界面、旋律、编曲和标志性音色；
- 以织物/毛毡作为环境与角色的主要质感，蜂蜡负责生命、花蜜与能量，浅色植鞣革负责蜂巢设施和 UI，刺绣负责运动与联系；
- 剪纸仅保留为已测试、近乎淘汰的历史候选，不作为后续资产生产基准；除非用户重新明确启用，否则不得据此生成或接入资产；
- 像素仅作为辅助数字纹理，除非未来另立完整像素原型；
- 先做一个代表性画面验证，再决定是否批量生产。

## 理由

2026-08-20 曾以低成本动画与强轮廓为理由提出剪纸主系统，但当日实际同时生成了毛毡立体场景、缝制布艺贴花和纸片等多张候选。归档时只提交了纸片图，使候选方向被误读为最终决定。用户随后确认剪纸已近乎抛弃，因此撤回该结论。织物/毛毡更符合温暖、自然、有生命力的基调；蜂蜡与皮革继续承担明确的世界语义。

## 后果

- 后续资产必须说明轮廓、材质和动画层级；
- 禁止用像素滤镜把现有矢量资产伪装成像素风；
- 后续代表性画面优先验证毛毡立体场景与布艺贴花两条非剪纸路线，再由用户确定最终抽象程度；
- 历史纸片图必须标为“淘汰候选”，不得单独展示成当前方向。
