# ADR-001：PVZ 参考边界与材质系统

状态：提案，待视觉原型验证

## 背景

用户喜欢初代《植物大战僵尸》的美术与音乐，同时提出像素、皮革、剪纸三种视觉概念。需要形成原创、可执行且不会拼贴失控的方向。

## 决策

- 参考 PVZ 的功能可读性、强轮廓、幽默与危险并存、动态音乐原则；
- 不复制具体角色、界面、旋律、编曲和标志性音色；
- 以剪纸作为主造型系统，蜂蜡/旧皮革作为 UI 和蜂巢次材质；
- 像素仅作为辅助数字纹理，除非未来另立完整像素原型；
- 先做一个代表性画面验证，再决定是否批量生产。

## 理由

剪纸最能同时连接节气色卡、强轮廓和低成本动画；蜂蜡与皮革能强化蜂巢“承载/储存”的语义。三者并列为主风格会引入互相冲突的分辨率、边缘和动画规则。

## 后果

- 后续资产必须说明轮廓、材质和动画层级；
- 禁止用像素滤镜把现有矢量/剪纸资产伪装成像素风；
- 需要用户用参考图确认剪纸锐利度、皮革强度和幽默程度。
